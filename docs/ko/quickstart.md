# 빠른 시작

[English](../quickstart.md) | [日本語](../ja/quickstart.md) | [繁體中文](../zh-TW/quickstart.md) | [한국어](../ko/quickstart.md) | [العربية](../ar/quickstart.md)

소스에서 설치하고 `FINGER_TRADER_ACCESS_TOKEN`을 설정한 뒤 `FingerTraderClient`를 context manager로 사용하세요. 예제는 시장, 상품, 과거 데이터와 지갑을 조회합니다. 토큰을 출력하지 마세요. 현재 앱 주문 쓰기는 지원되지 않으므로 주문을 제출하지 않습니다.

전체 메서드 세부사항, payload 필드, 제한 및 예제는 [영문 기술 문서](../quickstart.md)를 참조하세요.
