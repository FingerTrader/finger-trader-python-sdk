# P1 Hosted SDK 상태

[English](../../quant/p1-hosted-status.md) | [日本語](../../ja/quant/p1-hosted-status.md) | [繁體中文](../../zh-TW/quant/p1-hosted-status.md) | [한국어](p1-hosted-status.md) | [العربية](../../ar/quant/p1-hosted-status.md)

P1 구현은 개발 통합이며 플랫폼 승인이나 릴리스가 아닙니다. Hosted 거래는 `UNSUPPORTED_CAPABILITY`를 반환하며 브로커, 매칭, 원장, 실거래 기능은 포함되지 않습니다. 날짜별 증거와 도구 체인은 영문 상태 페이지를 참조하세요. 자세한 기준과 정확한 절차는 영문 원문을 참조하세요.
