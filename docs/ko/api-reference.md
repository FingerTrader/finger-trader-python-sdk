# 공개 API 참조

[English](../api-reference.md) | [日本語](../ja/api-reference.md) | [繁體中文](../zh-TW/api-reference.md) | [한국어](../ko/api-reference.md) | [العربية](../ar/api-reference.md)

공개 클라이언트는 `FingerTraderClient`와 auth, market_data, accounts, positions, orders 및 선택적 WebSocket 서비스를 포함합니다. HTTP 메서드는 `ApiResponse`를 반환합니다. Hosted Strategy API는 `finger_trader.hosted`에서 별도로 가져옵니다. 정확한 시그니처와 기본값은 영문 참조를 확인하세요.

전체 메서드 세부사항, payload 필드, 제한 및 예제는 [영문 기술 문서](../api-reference.md)를 참조하세요.
