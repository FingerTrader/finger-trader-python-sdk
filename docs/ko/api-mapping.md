# Finger_desk API 매핑

[English](../api-mapping.md) | [日本語](../ja/api-mapping.md) | [繁體中文](../zh-TW/api-mapping.md) | [한국어](../ko/api-mapping.md) | [العربية](../ar/api-mapping.md)

이 페이지는 확인된 Desktop API 호출과 SDK 메서드를 매핑합니다. OAuth, 시장 목록, 과거 봉, 세션 프로필, 지갑, 보유 포지션 및 주문 이력이 매핑되어 있습니다. 현재 앱의 주문 변경은 SDK에서 지원되지 않습니다. 정확한 endpoint와 payload는 영문 매핑 문서를 참조하세요.

전체 메서드 세부사항, payload 필드, 제한 및 예제는 [영문 기술 문서](../api-mapping.md)를 참조하세요.
