# 설치

[English](../installation.md) | [日本語](../ja/installation.md) | [繁體中文](../zh-TW/installation.md) | [한국어](../ko/installation.md) | [العربية](../ar/installation.md)

Python 3.10 이상이 필요합니다. PyPI에 게시되지 않았으므로 공식 저장소를 복제해 `python -m pip install .`로 설치하세요. WebSocket 사용 시에만 `.[websocket]`을 추가 설치합니다. 소스 설치만으로 Desktop Host가 제공되지는 않습니다.

전체 메서드 세부사항, payload 필드, 제한 및 예제는 [영문 기술 문서](../installation.md)를 참조하세요.
