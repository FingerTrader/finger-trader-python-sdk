# 快速開始

[English](../quickstart.md) | [日本語](../ja/quickstart.md) | [繁體中文](../zh-TW/quickstart.md) | [한국어](../ko/quickstart.md) | [العربية](../ar/quickstart.md)

從原始碼安裝，設定 `FINGER_TRADER_ACCESS_TOKEN`，並以 context manager 使用 `FingerTraderClient`。範例查詢市場、商品、歷史資料及錢包。請勿輸出權杖。快速開始不會送出訂單；目前 App 訂單寫入操作尚未支援。

完整方法細節、payload 欄位、限制與範例，請參閱[英文技術文件](../quickstart.md)。
