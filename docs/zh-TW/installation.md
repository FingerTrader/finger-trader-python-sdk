需要 Python 3.10 以上。目前尚未發布至 PyPI；請複製官方儲存庫並執行 `python -m pip install .`。只有使用 WebSocket 時才安裝 `.[websocket]`。單獨安裝原始碼不會提供 Desktop Host。

完整方法細節、payload 欄位、限制與範例，請參閱[英文技術文件](../installation.md)。
