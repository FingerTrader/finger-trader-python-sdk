تنفيذ P1 تكامل تطويري وليس قبولاً للمنصة أو إصداراً. تعيد طلبات تداول Hosted الرمز `UNSUPPORTED_CAPABILITY`؛ ولا يتضمن وسيطاً أو مطابقة أو دفتر تداول أو تنفيذ حي. راجع صفحة الحالة الإنجليزية للأدلة المؤرخة وسلسلة الأدوات. راجع النص الإنجليزي للإجراءات والمعايير الدقيقة.
