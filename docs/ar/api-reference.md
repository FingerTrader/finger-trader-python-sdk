# مرجع API العام

[English](../api-reference.md) | [日本語](../ja/api-reference.md) | [繁體中文](../zh-TW/api-reference.md) | [한국어](../ko/api-reference.md) | [العربية](../ar/api-reference.md)

تتضمن واجهة العميل العامة `FingerTraderClient` وخدمات auth وmarket_data وaccounts وpositions وorders وWebSocket الاختياري. تعيد أساليب HTTP كائن `ApiResponse`. تستورد واجهات Hosted Strategy منفصلة من `finger_trader.hosted`. راجع المرجع الإنجليزي للتواقيع والقيم الافتراضية الدقيقة.

للتفاصيل الكاملة للأساليب وحقول payload والقيود والأمثلة، راجع [المرجع التقني الإنجليزي](../api-reference.md).
