# التثبيت

[English](../installation.md) | [日本語](../ja/installation.md) | [繁體中文](../zh-TW/installation.md) | [한국어](../ko/installation.md) | [العربية](../ar/installation.md)

يتطلب Python 3.10 أو أحدث. لم ينشر على PyPI؛ استنسخ المستودع الرسمي وثبّت عبر `python -m pip install .`. ثبّت `.[websocket]` عند الحاجة إلى WebSocket فقط. لا يوفر تثبيت المصدر وحده Desktop Host.

للتفاصيل الكاملة للأساليب وحقول payload والقيود والأمثلة، راجع [المرجع التقني الإنجليزي](../installation.md).
