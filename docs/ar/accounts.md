# الحسابات والأرصدة

[English](../accounts.md) | [日本語](../ja/accounts.md) | [繁體中文](../zh-TW/accounts.md) | [한국어](../ko/accounts.md) | [العربية](../ar/accounts.md)

تقتصر استعلامات الملف الشخصي والمحفظة على الجلسة الموثقة. لا يسرد SDK معرّفات حسابات اعتباطية ولا يحسب حقوق الملكية أو الأموال المتاحة أو الهامش. استخدم `client.accounts.list()` و`.detail()` و`.balance()`؛ وتحدد استجابة الخادم الحقول والدقة.

للتفاصيل الكاملة للأساليب وحقول payload والقيود والأمثلة، راجع [المرجع التقني الإنجليزي](../accounts.md).
