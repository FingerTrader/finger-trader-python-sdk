# معمارية SDK ونطاقها

[English](../architecture.md) | [日本語](../ja/architecture.md) | [繁體中文](../zh-TW/architecture.md) | [한국어](../ko/architecture.md) | [العربية](../ar/architecture.md)

يفصل SDK بين HTTP المتزامن والاستراتيجيات المستضافة على Desktop وأدوات الإشارات المحلية. لا تنفذ استدعاءات HTTP الاستراتيجيات ولا تحاكي التداول. تستخدم الاستراتيجيات عقد worker/Host؛ ولا يتضمن Host الحالي من P1 وسيطاً أو محرك مطابقة أو دفتر تداول أو تنفيذ حي. يعالج `StrategyRunner` المحلي الشموع المقدمة من المستدعي فقط.

للتفاصيل الكاملة للأساليب وحقول payload والقيود والأمثلة، راجع [المرجع التقني الإنجليزي](../architecture.md).
