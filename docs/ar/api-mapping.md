# مطابقة API لـ Finger_desk

[English](../api-mapping.md) | [日本語](../ja/api-mapping.md) | [繁體中文](../zh-TW/api-mapping.md) | [한국어](../ko/api-mapping.md) | [العربية](../ar/api-mapping.md)

تربط هذه الصفحة استدعاءات Desktop المؤكدة بأساليب SDK. تشمل المطابقة OAuth وقوائم الأسواق والشموع التاريخية وملف الجلسة والمحفظة والمراكز وسجل الأوامر. لا يدعم SDK تغييرات الأوامر الحالية؛ راجع جدول المطابقة الإنجليزي للمسارات والحمولات والفجوات.

للتفاصيل الكاملة للأساليب وحقول payload والقيود والأمثلة، راجع [المرجع التقني الإنجليزي](../api-mapping.md).
