# クイックスタート

[English](../quickstart.md) | [日本語](../ja/quickstart.md) | [繁體中文](../zh-TW/quickstart.md) | [한국어](../ko/quickstart.md) | [العربية](../ar/quickstart.md)

Install from source, set `FINGER_TRADER_ACCESS_TOKEN`, and use `FingerTraderClient` as a context manager. Examples query markets, products, history, and wallet data. Do not print tokens. The quickstart does not submit orders; current app order writes are unsupported.

For complete method details, payload fields, limitations, and examples, see the [English technical reference](../quickstart.md).
