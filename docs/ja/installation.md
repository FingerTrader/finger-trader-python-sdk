Requires Python 3.10 or newer. PyPI publication is not available; clone the official repository and install with `python -m pip install .`. Install `.[websocket]` only when using WebSocket. A source install alone does not provide a Desktop Host.

For complete method details, payload fields, limitations, and examples, see the [English technical reference](../installation.md).
