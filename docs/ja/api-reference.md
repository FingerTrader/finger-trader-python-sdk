# 公開 API リファレンス

[English](../api-reference.md) | [日本語](../ja/api-reference.md) | [繁體中文](../zh-TW/api-reference.md) | [한국어](../ko/api-reference.md) | [العربية](../ar/api-reference.md)

The public client surface includes `FingerTraderClient` and auth, market_data, accounts, positions, orders, and optional WebSocket services. HTTP methods return `ApiResponse`. Hosted strategy APIs are separately imported from `finger_trader.hosted`. See the canonical reference for exact signatures and defaults.

For complete method details, payload fields, limitations, and examples, see the [English technical reference](../api-reference.md).
